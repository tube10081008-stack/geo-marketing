# 🥕 당근마켓 쿠폰 설계 (v1)

> 상위 문서: [DETAILING-PLAYBOOK.md §7.4](../DETAILING-PLAYBOOK.md) · 유입 기록: [배포기록표.xlsx](./README.md)
> ⚠️ 당근 비즈프로필의 메뉴 구성과 쿠폰 옵션은 수시로 바뀐다. 아래 **설정값은 앱에서 실제 화면을 보고 맞춰 넣는다.**

---

## 0. 먼저 — 이 사업에서 할인 쿠폰은 위험하다

쿠폰을 만들기 전에 이 세 가지를 알고 시작해야 한다.

**① 할인은 가장 나쁜 고객을 부른다.**
"첫 세차 50% 할인"에 가장 먼저 반응하는 사람은 **한 달 이상 방치해 둔 차의 주인**이다. 그런데 그 차는 [§4.4 오염도 4~5등급](../DETAILING-PLAYBOOK.md)이라 **워터리스 시공을 거절해야 하는 차**다. 쿠폰을 들고 온 사람을 돌려보내는 상황이 생기고, 그게 당근 후기로 남는다.

**② 할인은 밀도를 만들지 않는다.**
[§0](../DETAILING-PLAYBOOK.md)의 결론은 *단지 밀도가 유일한 진짜 레버*다. 그런데 쿠폰은 운정 전역에 흩뿌려져 **분산형 고객**을 만든다. 이동시간이 늘어 하루 대수가 줄고, 할인까지 줬으니 두 번 손해다.

**③ 구독 모델은 1회 체험 할인과 궁합이 나쁘다.**
우리 상품의 가치는 *매주 온다*는 것이지 *한 번 싸게 해준다*가 아니다. 1회 할인은 1회만 쓰는 사람을 부른다.

### 그래서 설계 원칙을 바꾼다

> **할인해 주지 말고, 먼저 주거나, 이웃을 모으게 하라.**

게릴라 배포가 작동하는 이유는 싸서가 아니라 **먼저 무료로 시공하고 실력을 보여주기 때문**이다([§7.1](../DETAILING-PLAYBOOK.md)). 당근 쿠폰은 **그 구조를 온라인으로 옮기는 도구**로 쓴다.

## 1. 쿠폰 3종

### 🥇 쿠폰 A — 무료 타이어 코팅 (주력 · 신규 획득)

게릴라 퍼널의 온라인 버전이다. 원가 **480원**(다크사이드 5mL), 시공 **3분**. 대면 접점을 만들고 실력을 보여주는 것이 목적이지 세차를 파는 게 아니다.

| 설정 | 값 |
| --- | --- |
| 종류 | **증정 (무료 제공)** — 할인이 아니다 |
| 발급 수량 | **주 20장 한정** ← 캐파 통제 장치. 반드시 건다 |
| 유효기간 | 발급일로부터 **14일** |
| 사용 조건 | 파주 운정 지역 아파트 **지하주차장** 주차 차량 / 1인 1회 |

**쿠폰 문구**
```
타이어 코팅 무료 시공

사이드월이 갈변된 타이어를 프리미엄 코팅제로 되살려 드립니다.
3분이면 끝나고, 비용은 받지 않습니다.

세차를 권하지 않습니다. 코팅만 해드리고 갑니다.
마음에 드시면 그때 연락 주세요.

· 운정 지역 아파트 지하주차장 주차 차량
· 차를 옮기실 필요 없습니다
· 주 20대 한정
```

> 📌 **"세차를 권하지 않습니다"가 이 쿠폰의 핵심 문장이다.** 팔지 않고 주기만 할 때 상호성이 작동한다. 붙잡고 설명하는 순간 전환율이 떨어진다([§7.1 칭찬 화법](../DETAILING-PLAYBOOK.md)).

**운영 규칙**
- 요청이 오면 **단지별로 모아서 하루에 처리**한다. 한 대씩 흩어져 다니면 이동시간에 잡아먹힌다
- 시공 후 **전단을 남긴다** — 코드가 박힌 그 전단이다(§4 추적)
- 주 20장을 넘기지 않는다. 무료 시공이 유료 시공 시간을 침범하면 본말전도다

---

### 🥈 쿠폰 B — 이웃 모집 (밀도 생성 · 가장 중요)

**할인을 밀도와 교환하는 쿠폰이다.** 고객이 대신 영업해 주므로 CAC가 사실상 0이 된다.

| 설정 | 값 |
| --- | --- |
| 종류 | 할인 (정률) |
| 혜택 | **첫 달 20% 할인 (80,000 → 64,000원)** |
| 조건 | **같은 단지에서 3명 이상 동시 신청 시** 전원 적용 |
| 유효기간 | 60일 (모으는 데 시간이 걸린다) |
| 중복 | 단체 할인(5대 이상 19,000원)과 **중복 불가** |

**쿠폰 문구**
```
이웃 3명이면 첫 달 20% 할인

같은 단지에서 3분 이상 함께 신청하시면 전원 첫 달 64,000원입니다.
한 단지에 모여 있으면 이동 시간이 줄어들고, 그만큼을 돌려드립니다.

신청이 5대를 넘으면 그 단지에 요일 고정 방문을 개설합니다.
(예: 가람마을 3단지 매주 화요일 오전)

· 단톡방에 이 쿠폰을 공유해 주세요
· 대표 한 분만 문자 주시면 나머지는 저희가 진행합니다
```

> 📌 인당 할인액 16,000원이다. 게릴라 보수 시나리오 CAC(61,000원)의 **4분의 1**이고, 이웃 소개라 이탈률도 낮다.

### 🥉 쿠폰 C — 구독 첫 달 (전환 마감)

이미 관심 있는 사람의 마지막 망설임을 없애는 쿠폰이다.

| 설정 | 값 |
| --- | --- |
| 종류 | 할인 (정액) |
| 혜택 | **첫 달 10,000원 할인 (80,000 → 70,000원)** |
| 유효기간 | 30일 |
| 조건 | 정기권 신규 가입 시 / 1인 1회 |

**쿠폰 문구**
```
정기권 첫 달 10,000원 할인

주 1회 방문 관리 월 80,000원 → 첫 달 70,000원

· 차는 세워둔 자리에 그대로 두시면 됩니다
· 요일을 정해두면 매주 그 시간에 갑니다
· 매회 작업 전후 사진을 보내드립니다
```

> 🔴 **금액을 전단과 반드시 같게 유지한다.** 전단도 "첫 달 10,000원 할인"이다. 채널마다 할인액이 다르면 *"전단은 1만 원인데 당근은 2만 원이네"* 가 되고, 신뢰가 깨진다.

## 2. 배포 — 쿠폰만 만들면 아무도 안 본다

| 경로 | 방법 |
| --- | --- |
| **비즈프로필 소식** | 쿠폰을 첨부해 글로 올린다. 주 1~2회. 사진은 [비포/애프터](../INSTAGRAM-PLAYBOOK.md)를 그대로 재사용한다 — 이미 찍어둔 것이라 추가 노동이 없다 |
| **단골 알림** | 단골이 쌓이면 새 쿠폰 발행 시 알림이 간다. **단골 확보가 곧 재발송 자산**이므로 초기엔 단골 늘리기를 우선한다 |
| **동네생활** | ⚠️ **홍보글은 삭제된다.** 정보성 글로만 접근한다 — "지하주차장에서 세차해도 되나요?(법적으로)" 같은 글로 신뢰를 선점하고 프로필로 유입시킨다([§7.4](../DETAILING-PLAYBOOK.md)) |
| **당근 광고 (유료)** | 동네 단위 타깃이 가능해 이 사업과 맞다. 다만 **쿠폰 A의 반응을 먼저 본 뒤** 집행한다. 무료 채널이 안 먹히는데 돈을 넣으면 안 된다 |

**소식 글 예시 (쿠폰 A 첨부)**
```
운정 아파트 지하주차장에서 세차합니다. 물은 안 씁니다.

고압수 대신 약제로 오염을 띄운 뒤 극세사 타월로 걷어냅니다.
한 대에 타월 12장을 쓰고, 쓴 타월은 다시 담그지 않습니다.
바닥에 물이 한 방울도 남지 않아 관리사무소에서 제지받을 일이 없습니다.

이번 주는 타이어 코팅을 무료로 해드립니다. 3분이면 끝납니다.
세차를 권하지 않습니다. 코팅만 해드리고 갑니다.

[쿠폰 받기]
```

## 3. 유입 추적

당근으로 들어온 문의는 [문의접수 시트](./README.md)에 이렇게 남긴다.

| 칸 | 값 |
| --- | --- |
| `유입경로` | **당근** (드롭다운에 이미 있다) |
| `코드` | 비워둔다 — WJ 코드는 전단 실험용이라 섞으면 분모가 오염된다 |
| `메모` | **단지명을 반드시 적는다** ← 쿠폰 B의 밀도 효과를 보려면 이게 필요하다 |

요약 시트의 **채널별** 블록에서 당근의 문의 수·전환·성사율이 자동으로 잡힌다.

> 💡 단지별 집계까지 자동화하려면 문의접수에 `단지명` 열을 하나 추가하면 된다. 지금은 메모 칸으로 충분하지만, 당근 유입이 월 10건을 넘으면 열을 만드는 게 낫다.

## 4. 쿠폰과 전단을 섞지 않는다

두 채널의 추적 장치가 다르다. 겹치면 둘 다 못 읽는다.

| | 전단 | 당근 |
| --- | --- | --- |
| 추적 | `WJ-A1` 코드 | 쿠폰 사용 이력 |
| 기록 | 유입경로 = **QR문자 / 전화** | 유입경로 = **당근** |
| 분모 | 배포 대수 (수기 입력) | 쿠폰 발급 수 (당근이 집계) |

쿠폰 A 시공 후 전단을 남기는 건 괜찮다. 그 사람이 나중에 전단 코드로 연락하면 **먼저 접촉한 경로(당근)로 기록**한다.

## 5. 하지 말 것

| 금지 | 이유 |
| --- | --- |
| **"첫 세차 50% 할인"류 파격 할인** | §0에서 설명한 대로 방치 차량과 체리피커를 부른다 |
| 쿠폰 남발 (상시 발행) | 정가가 무의미해진다. 쿠폰 C는 신규 전용으로만 유지 |
| 무료 시공 무제한 | 주 20장 상한을 넘기면 유료 시공 시간을 잡아먹는다 |
| 동네생활 홍보글 | 삭제 대상이고, 반복하면 계정 제재 |
| 후기 요청 대가 지급 | 절대 금지. 지역 커뮤니티는 좁고 한 번 걸리면 끝난다([§7.4](../DETAILING-PLAYBOOK.md)) |
| 오염도 4~5등급 쿠폰 수용 | 쿠폰을 들고 왔어도 **거절 기준은 그대로다.** 쿠폰 문구에 조건을 미리 넣어 현장 분쟁을 막는다 |

## 6. 90일 판정

| 지표 | 목표 | 판단 |
| --- | --- | --- |
| 쿠폰 A 사용 | 월 20건 이상 | 대면 접점이 생기고 있다 |
| 쿠폰 A → 구독 전환 | **10% 이상** | 게릴라 낙관 시나리오와 같은 수준. 미달이면 화법·타깃을 점검 |
| 쿠폰 B 사용 | 분기 1건 이상 | 1건만 성사돼도 단지 하나가 열린다 |
| 당근 경유 구독 | 월 2명 이상 | 유지. 미달이면 소식 발행 빈도부터 올린다 |
| 단골 수 | 꾸준한 증가 | 재발송 자산. 정체되면 콘텐츠 문제다 |

> 쿠폰 B가 **분기 1건만 성사돼도 이 채널은 성공**이다. 단지 하나가 열리면 요일 고정 방문이 생기고, 그게 [§0의 초집중 시나리오](../DETAILING-PLAYBOOK.md)로 가는 입구다.

## 7. 첫 2주 실행 순서

| 시점 | 할 일 |
| --- | --- |
| 1일차 | 당근 **비즈프로필 개설**, 지역·업종·소개 설정. 소개 문구는 [홈페이지 원고](./WEBSITE-HANDOFF.md) 히어로 문구를 그대로 쓴다 |
| 2일차 | **쿠폰 A 생성** (주 20장, 14일). 비포/애프터 사진 3장으로 첫 소식 발행 |
| 3~7일차 | 요청이 오면 **단지별로 모아서** 무료 시공. 시공 후 전단을 남긴다 |
| 2주차 | **쿠폰 C 생성**. 동네생활에 정보성 글 1편("지하주차장에서 세차해도 되나요?") |
| 3주차~ | 단골 100명이 넘으면 **쿠폰 B 발행** — 이웃을 모을 모수가 생긴 시점이다 |

> 쿠폰 B를 먼저 내지 않는다. 단골이 없으면 이웃을 모을 사람 자체가 없다.
