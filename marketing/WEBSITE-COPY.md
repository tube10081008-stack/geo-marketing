## 왜 바꾸는가

기존 헤드라인 `물 한 방울 없이 / 주차장에서 끝나는 세차`의 문제는 **뒷줄이 아니라 앞줄**이다.

일반인의 상식은 `세차 = 물`이다. "물을 안 쓴다"는 말에 차주가 먼저 떠올리는 건 감탄이 아니라 **"그럼 제대로 되나?"** 다. 폴리머 캡슐화·롤링 오프는 **설득이 필요한 내용**인데, 헤드라인은 설득을 시작하는 자리가 아니라 관심을 잡는 자리다. 여기서 의심이 걸리면 아래를 안 읽는다.

무유출은 **"왜 지하주차장에서 되지?"를 이미 궁금해하는 사람에게 주는 답**이다. 그래서 헤드라인이 아니라 근거 자리로 내린다. (전단도 같은 이유로 앞면은 고객 이익, 뒷면에서 원리를 설명한다.)

## 2. 히어로

**아이브로우**
```
파주 운정신도시 아파트 전담
```

**헤드라인**
```
차는 그 자리에 두세요
매주 한 번, 주차장으로 갑니다
```

**서브헤드**
```
출근 전에 세워두시면 점심 전에 끝납니다. 물을 쓰지 않아 차를 옮기지 않고
지하주차장에서 그대로 작업합니다. 배수도, 소음도, 냄새도 남지 않습니다.
```

**CTA**
```
[ 문자로 예약하기 ]   [ 32단계 공정 보기 ]
문자로만 예약받습니다 · 결제는 작업 후
```

> 📌 두 번째 CTA는 **"32단계"라는 숫자를 되살린다.** `작업 공정 보기`는 밋밋하다 — 숫자가 주는 구체성이 프리미엄을 만든다. 아래 섹션 제목만 "주요 공정"으로 두면 모순이 아니다.

**헤드라인 대안 (톤에 따라 선택)**

| 안 | 문구 | 강조점 |
| --- | --- | --- |
| **A (추천)** | 차는 그 자리에 두세요 / 매주 한 번, 주차장으로 갑니다 | 무노동 + 정기 + 방문 |
| B | 세차를 잊어도 / 차는 늘 깨끗합니다 | 위임 · 상시 청결 |
| C | 주말을 세차장에서 / 보내지 마세요 | 시간 회수 |
| D (최소 수정) | 차는 그 자리에 두세요, / 주차장에서 끝나는 세차 | 기존 구조 유지 |

A를 권한다. 주력 상품이 정기권인데 기존 헤드라인은 1회성으로 읽혔다 — A는 "매주 한 번"으로 그것까지 해결한다.

## 3. 기준 스탯 — 그대로 둔다

`0L / 12장 / 4컷 / 24시간` 구성은 손대지 않는다. **허위 실적을 뺀 자리에 검증 가능한 기준을 넣은 것이 이 사이트에서 가장 잘한 부분이다.** 누적 1,200대는 누구나 쓸 수 있지만 "타월 12장, 다시 담그지 않습니다"는 진짜 하는 사람만 쓸 수 있다.

> ⚠️ 보험만 아직 미검증이다. **실제 가입 전에는 `영업배상책임보험 가입 · 한도 1억원` 문구를 올리지 않는다.**

## 4. "무엇이 다른가" — 헤드를 고객 이익으로

기술명을 제목에 두면 차주가 읽을 이유가 없다. **제목은 이익, 본문은 근거** 순서로 뒤집는다.

| | 기존 제목 | **수정 제목** | 본문 |
| --- | --- | --- | --- |
| 01 | 서류부터 드립니다 | **서류부터 드립니다** *(유지)* | 보험증권·사업자등록증·작업계획서를 입주자대표회의 검토용 PDF로 먼저 제출합니다. |
| 02 | 타월은 한 면당 한 번 | **씻을수록 잔기스가 느는 걸 막습니다** | 고압수 대신 폴리머로 오염을 띄워 걷어냅니다. 한 대에 극세사 타월 12장을 쓰고, 쓴 것은 다시 담그지 않습니다. |
| 03 | 전담 담당자 고정 | **매번 같은 사람이 옵니다** | 정기권은 담당자가 고정됩니다. 차량 이력이 이어지고, 매번 처음부터 설명할 일이 없습니다. |
| 04 | 작업 전후 4컷 리포트 | **자리를 비우셔도 됩니다** | 작업 전후 4컷을 문자로 보냅니다. 기존 흠집까지 먼저 기록해 두기 때문에 나중에 얼굴 붉힐 일이 없습니다. |

큰 블록 2개도 같은 원칙으로:

| 기존 제목 | **수정 제목** |
| --- | --- |
| 바닥에 물이 흐르지 않습니다 | **옆 차에 물이 튀지 않습니다** |
| 소음도 배기도 없습니다 | **저녁에도 작업할 수 있습니다** |

> 본문은 그대로 둬도 된다. 제목만 "우리가 안 하는 것" → "당신에게 좋은 것"으로 바꾸는 작업이다.

## 5. 가격 — 80,000원 기준 재설계

```
1회 · 외부            39,000원   40분
정기권 · 월 4회       80,000원   회당 20,000원   ← 주력
1회 · 실내외          75,000원   70분
정기권 프리미엄      120,000원   월 4회 + 매회 실내
```

**정기권 카드 문구**
```
정기권 · 월 4회
80,000원
회당 20,000원 · 요일 지정 방문

1회 39,000원 → 정기권 회당 20,000원
같은 작업을 절반 값에 받으십니다

4주 사이클 — 매주 다른 관리가 들어갑니다
W1  외부 워터리스 · 휠
W2  + 유리 유막 제거
W3  + 가죽 · 대시보드 케어
W4  + 타이어 코팅 · 전담자 점검

전담 담당자 고정 · 차량 이력 관리
```

> 📌 **1회 39,000 대비 회당 20,000은 49% 차이다.** 이 격차 자체가 가장 강력한 구독 전환 장치이므로 **숫자를 나란히 붙여 보여준다.** 기존 124,000원 안에서는 이 대비가 20%밖에 안 돼 약했다.
> 📌 프리미엄 티어(120,000원)는 [§8.2](../DETAILING-PLAYBOOK.md)의 설계 그대로다. **기존 고객 인상보다 신규를 상위 티어로 받는 게 저항이 적다.**

**각주 (반드시 넣는다)**
```
※ 한 달 이상 방치되어 흙·모래가 두껍게 앉은 차량은 흠집 위험이 있어
   무유출 세차를 진행하지 않습니다. 예약 전에 먼저 알려드립니다.
```
> 🔴 [§4.4 오염도 거절 기준](../DETAILING-PLAYBOOK.md)은 **사업 생존 규칙**이다. 사이트에 이 문장이 없으면 방치 차량이 39,000원 결제하고 예약을 건다.

## 6. 단체 할인 — 폭을 줄인다

80,000원은 이미 침투 가격이라 할인 여지가 작다.

```
정기권 1~4대        20,000원   (월 80,000원)
같은 단지 5대 이상   19,000원   (월 76,000원)
같은 단지 10대 이상  18,000원   (월 72,000원)
회당 금액 기준 · 같은 요일 방문 조건
```

> ⚠️ **할인이 밀도 이득을 깎는다는 걸 알고 쓴다.** 분산형(월 192회 × 20,000 = 384만) 대비 집중형(월 250회 × 18,000 = 450만)의 이득은 66만이다. 할인이 없다면 116만이었을 것이므로 **할인이 밀도 프리미엄의 약 43%를 먹는다.**
> 그래도 유지할 이유는 **고객이 이웃을 모아와 CAC가 0이 되기 때문**이다. 다만 3개월 안에 10대 단지가 하나도 안 나오면 **18,000 구간은 접는다** — 할인만 주고 밀도는 못 얻는 상태이므로.

**대안 (가격 훼손 없이 같은 효과)**
```
이웃 4대를 함께 신청해주시면, 소개해주신 분은 그 달 무료입니다.
```
단가를 지키면서 추천 유인은 더 강하다. 둘 중 하나만 쓴다.

네. 주차된 상태 그대로 시공합니다. 열쇠도, 이동도 필요 없습니다.

비 오는 날은 어떻게 하나요?

많이 더러운 상태여도 되나요?
흙·모래가 두껍게 앉았다면 흠집 위험이 있어 먼저 알려드립니다.

물을 안 쓰는데 정말 깨끗해지나요?
오염을 문질러 벗기는 게 아니라, 약제로 띄운 뒤 걷어냅니다.
고압수 세차보다 도장면에 남는 잔기스가 적습니다.

관리사무소에서 막지 않나요?

사전 협의가 필요한 단지는 저희가 먼저 연락드립니다.

## 10. 입대의 트랙은 아래쪽에 그대로 둔다

헤드라인을 차주 언어로 바꾸되 **입대의 공략을 버리지 않는다.** [§0](../DETAILING-PLAYBOOK.md) 기준 10대 이상 단지 하나를 잡는 것이 가장 빠른 밀도 확보 경로이고, "서류부터 드립니다"는 그 트랙의 최고 무기다.

```
위쪽 절반 (히어로 ~ 가격)  → 차주
아래쪽    (단체 신청, 입대의 자료 요청) → 입주자대표회의
```

지금 구조는 이미 맞다. 헤드라인까지 입대의 언어였던 것이 문제였을 뿐이다.
