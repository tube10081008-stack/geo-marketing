## 14. 개발 명세

### 14.1 "문자로 예약하기" 버튼

문자 앱을 열면서 본문을 미리 채운다. 전단 QR(`SMSTO:`)과 같은 방식이라 유입 경로가 일관된다.

```html
<a href="sms:01059314144?&body=[전단코드] %0A단지 : %0A동/주차구역 : %0A희망 시간대 : ">
  문자로 예약하기
</a>
```

- `%0A` = 줄바꿈
- `?&body=` 형태가 iOS·안드로이드 양쪽에서 가장 잘 동작한다
- ⚠️ **아이폰과 안드로이드에서 각각 한 번씩 눌러보고 공개한다.** 문자창이 안 열리면 예약이 통째로 유실된다

### 14.2 전단 코드 자동 입력

전단을 보고 `?ref=WJ-A1`로 들어온 방문자는 코드를 자동으로 채워준다. 손으로 적게 하면 새어나간다.

```html
<script>
  const ref = new URLSearchParams(location.search).get('ref') || '';
  if (ref) {
    // 예약 폼 입력란에 채우기
    document.querySelectorAll('[data-ref-field]').forEach(el => el.value = ref);
    // 문자 버튼의 본문에도 반영
    document.querySelectorAll('a[href^="sms:"]').forEach(a => {
      a.href = a.href.replace('[전단코드]', '[' + ref + ']');
    });
  }
</script>
```

전단 QR과 짝이 맞는 코드 체계는 [marketing/README.md](./README.md) 참고 (`WJ-A1` = 운정·A단지·1차 배포).

### 14.3 문의가 오면

문자에 찍혀 온 코드를 [`배포기록표.xlsx`](./배포기록표.xlsx) **문의접수** 시트에 기록한다.
- 전단으로 온 문의 → `유입경로`를 **QR문자**
- 홈페이지에서 코드 없이 온 문의 → **기타** (또는 채널을 하나 더 만들어 구분)
