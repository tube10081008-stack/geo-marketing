실행 액션

근거 인용 [M#] · 측정 목표 포함
근거 수치는 원 연구의 맥락(주로 해외 데이터) 기준의 방향성 지침입니다. 실제 효과는 이 가게의 실측 A/B로 검증하며, 데모(stub) 응답에는 포인트가 차감되지 않습니다.

업종 벤치마크

내 증가율 vs 동종업종 중앙값 · 익명 집계 · 계절성 통제
같은 업종 가입 업체들의 최근 90일 증가율을 익명 집계한 값입니다. 개별 업체 정보는 노출되지 않으며, 표본이 10곳 미만인 지표는 왜곡 방지를 위해 표본이 찰 때까지 업종 값을 숨깁니다. '차분(%p)'이 업종 전체 흐름(계절 특수 등)을 뺀 순수 개선 신호입니다.
